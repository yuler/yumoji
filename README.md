# Yumoji（吃吃贴纸）

> 把每一口好吃的，收成一枚贴纸
>
> Every yummy bite, a sticker.

Yumoji = **yummy** + **emoji**。

一款原生 Swift 开发的 iOS 饮食记录应用：拍一下今天吃的，食物被抠成一枚贴纸收进日历，AI 顺手给出菜名、大致热量和一句简介。

## 核心体验

- **拍一口**：打开相机拍下这一餐。
- **收一枚**：自动抠出食物主体，做成带白边的贴纸。
- **看一眼**：AI 给出菜名、估算热量和食物简介，热量只是粗估，可以手改。
- **翻一翻**：在日历里回看每天吃过的贴纸。

## 原型预览

直接用浏览器打开 `prototypes/core-loop/index.html`，即可体验和 `ios/Yumoji` 当前实现一致的 MVP 页面：首页 → 拍一张 / 从相册选一张 → 抠图贴纸、识别结果与调试参数。贴纸按 `StickerCompositor` 的步骤在浏览器里合成，识别结果与 `MockFoodAnalyzer` 相同；右侧「原型控制」可模拟无相机、抠图失败、不是食物、识别失败等情况。
